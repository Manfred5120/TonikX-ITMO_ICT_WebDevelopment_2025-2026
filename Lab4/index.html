    Лабораторная работа №4 Реализация клиентской части средствами Vue.js

    Студент: Митрофанов Георгий Университет: ИТМО
    Группа: К3339

    1. Структура маршрутов

    • /login - Страница входа
    • /register - Страница регистрации
    • / - Главная страница (список файлов и папок)
    • /folder/:id - Просмотр содержимого папки
    • /profile - Профиль пользователя

    2. Описание интерфейсов

    2.1 Страница входа (Login)

    URL: /login

    API запрос: POST /api/auth/jwt/create/

    Назначение: авторизация пользователя в системе.

    Функции: - ввод имени пользователя - ввод пароля - отправка запроса авторизации - сохранение JWT токена в localStorage - редирект на главную страницу после успешного входа

    2.2 Страница регистрации (Register)

    URL: /register

    API запрос: POST /api/auth/users/

    Назначение: создание нового пользователя.

    Функции: - ввод имени пользователя - ввод email (опционально) - ввод пароля - подтверждение пароля - автоматический вход после успешной регистрации

    2.3 Главная страница (Files)

    URL: /

    API запросы: - GET /api/files/ — получение списка файлов - GET /api/folders/ — получение списка папок - POST /api/files/bulk_upload/ — загрузка файлов - POST /api/folders/ — создание папки

    Назначение: управление файлами и папками пользователя.

    Функции: - просмотр всех файлов и папок в корневой директории - загрузка новых файлов (один или несколько) - создание новой папки - переход в папку по клику - отображение размера и типа файлов - кнопки действий для каждого файла

    2.4 Страница папки (Folder)

    URL: /folder/:id

    API запросы: - GET /api/folders/{id}/content/ — содержимое папки - GET /api/folders/{id}/ — информация о папке

    Назначение: просмотр содержимого конкретной папки.

    Функции: - просмотр файлов и вложенных папок - навигация "назад" к родительской папке - отображение пути к текущей папке - загрузка файлов в текущую папку - создание вложенной папки

    2.5 Действия с файлами

    Просмотр файла

    API запрос: GET /api/files/{id}/

    При клике на файл открывается страница с детальной информацией: - имя файла - размер - тип (MIME) - дата загрузки - предпросмотр (для изображений)

    Скачивание файла

    API запрос: GET /api/files/{id}/download/

    Кнопка "Скачать" на карточке файла инициирует загрузку файла на устройство пользователя.

    Удаление файла

    API запрос: DELETE /api/files/{id}/

    Кнопка "Удалить" помечает файл как удалённый (мягкое удаление). Файл исчезает из списка, но сохраняется в базе.

    Расшаривание файла

    API запрос: POST /api/files/{id}/share/

    Кнопка "Поделиться" создаёт публичную ссылку на файл: - указывается время жизни ссылки (в минутах) - указывается максимальное количество скачиваний - генерируется уникальный токен - ссылка копируется в буфер обмена

    Перемещение файла

    API запрос: POST /api/files/{id}/move/

    Возможность переместить файл в другую папку: - открывается список папок - выбор целевой папки - подтверждение перемещения

    2.6 Действия с папками

    Создание папки

    API запрос: POST /api/folders/

    Модальное окно с полем для ввода имени новой папки.

    Переименование папки

    API запрос: PATCH /api/folders/{id}/

    Изменение имени существующей папки.

    Удаление папки

    API запрос: DELETE /api/folders/{id}/

    Удаление папки вместе со всем содержимым (файлы помечаются как удалённые).

    2.7 Страница профиля (Profile)

    URL: /profile

    API запросы: - GET /api/auth/users/me/ — получение данных - PATCH /api/auth/users/me/ — обновление данных - POST /api/auth/users/set_password/ — смена пароля

    Назначение: управление данными пользователя.

    Функции: - просмотр имени пользователя и email - изменение email - изменение пароля (старый пароль, новый пароль, подтверждение) - выход из аккаунта (очистка токена)

    2.8 Публичный доступ (Public Link)

    URL: /p/:token

    API запрос: GET /p/{token}/

    Назначение: доступ к файлу по публичной ссылке без авторизации.

    Функции: - проверка срока действия ссылки - проверка лимита скачиваний - автоматическое скачивание файла - отображение ошибки, если ссылка истекла

    3. API запросы

    3.1 Авторизация (Auth)

    Метод Эндпоинт Описание Тело запроса Ответ
    POST /api/auth/users/ Регистрация нового пользователя { "username": "user", "password": "pass" } Данные созданного пользователя
    POST /api/auth/jwt/create/ Получение JWT токена (вход) { "username": "user", "password": "pass" } { "access": "token", "refresh": "token" }
    POST /api/auth/jwt/refresh/ Обновление access токена { "refresh": "token" } { "access": "new_token" }
    GET /api/auth/users/me/ Информация о текущем пользователе - Данные пользователя
    PATCH /api/auth/users/me/ Обновление данных пользователя { "email": "new@mail.com" } Обновлённые данные
    POST /api/auth/users/set_password/ Смена пароля { "new_password": "newpass", "current_password": "oldpass" } 204 No Content

    3.2 Файлы (Files)

    Метод Эндпоинт Описание Параметры Тело запроса Ответ
    GET /api/files/ Список всех файлов пользователя - - Массив файлов
    POST /api/files/ Загрузить один файл - multipart/form-data с полем file Данные загруженного файла
    GET /api/files/{id}/ Детальная информация о файле ID файла - Данные файла
    DELETE /api/files/{id}/ Удалить файл (мягкое удаление) ID файла - 204 No Content
    GET /api/files/{id}/download/ Скачать файл ID файла - Файл для скачивания
    GET /api/files/{id}/preview/ Получить превью файла ID файла - Изображение-превью
    POST /api/files/{id}/move/ Переместить файл в папку ID файла { "folder_id": 5 } { "message": "Файл перемещен" }
    POST /api/files/{id}/share/ Создать публичную ссылку ID файла { "ttl_minutes": 60, "max_downloads": 5 } { "url": "/p/token/" }
    POST /api/files/bulk_upload/ Загрузить несколько файлов - multipart/form-data с полем files Массив загруженных файлов

    3.3 Папки (Folders)

    Метод Эндпоинт Описание Параметры Тело запроса Ответ
    GET /api/folders/ Список всех папок пользователя - - Массив папок
    POST /api/folders/ Создать новую папку - { "name": "Новая папка", "parent": null } Данные созданной папки
    GET /api/folders/{id}/ Информация о папке ID папки - Данные папки
    PUT/PATCH /api/folders/{id}/ Обновить папку (переименовать) ID папки { "name": "Новое имя" } Обновлённые данные
    DELETE /api/folders/{id}/ Удалить папку ID папки - 204 No Content
    GET /api/folders/{id}/content/ Содержимое папки ID папки - { "folders": [], "files": [] }

    3.4 Публичные ссылки (Public)

    Метод Эндпоинт Описание Параметры Ответ
    GET /p/{token}/ Доступ к файлу по публичной ссылке Токен ссылки Файл для скачивания или ошибка 404

    3.5 Документация

    Метод Эндпоинт Описание
    GET /swagger/ Swagger UI — интерактивная документация API
    GET /redoc/ ReDoc — альтернативная документация
    GET /swagger.json/ JSON схема API

    4. Компоненты Vue

    4.1 App.vue (корневой компонент)

    Корневой компонент приложения, содержит основную структуру и роутер.

    <template>
  <div id="app">
    <NavBar v-if="!isAuthPage" />
    <router-view />
  </div>
</template>

    Назначение: - Отображает навигационную панель на всех страницах, кроме страниц входа/регистрации - Подключает роутер для отображения текущей страницы

    4.2 NavBar (навигационная панель)

    Компонент навигации, отображается на всех страницах после авторизации.

    Отображает: - Логотип/название приложения - Ссылку на главную страницу (файлы) - Ссылку на профиль пользователя - Имя текущего пользователя - Кнопку "Выйти"

    Функции: - Навигация между разделами - Выход из аккаунта (очистка токена, редирект на логин)

    4.3 FileCard (карточка файла)

    Компонент для отображения файла в списке.

    Пропсы (входные данные): - file — объект с данными файла (id, name, size, mime_type, uploaded_at)

    Отображает: - Иконка в зависимости от типа файла (изображение, видео, pdf, документ) - Имя файла - Размер (в байтах/KB/MB) - Дата загрузки - Кнопки действий

    Кнопки действий: - Скачать — вызывает API /api/files/{id}/download/ - Поделиться — открывает модальное окно для создания ссылки - Удалить — подтверждение удаления, затем вызов API DELETE /api/files/{id}/ - Переместить — открывает список папок для выбора

    События (emits): - @delete — событие удаления файла - @share — событие расшаривания - @move — событие перемещения

    <template>
  <div class="file-card">
    <div class="file-icon">📄</div>
    <div class="file-info">
      <div class="file-name">{{ file.name }}</div>
      <div class="file-meta">{{ formatSize(file.size) }} • {{ formatDate(file.uploaded_at) }}</div>
    </div>
    <div class="file-actions">
      <button @click="downloadFile">Скачать</button>
      <button @click="shareFile">Поделиться</button>
      <button @click="deleteFile">Удалить</button>
    </div>
  </div>
</template>

    4.4 FolderCard (карточка папки)

    Компонент для отображения папки в списке.

    Пропсы: - folder — объект с данными папки (id, name, created_at)

    Отображает: - Иконка папки - Название папки - Дата создания - Кнопки действий

    Кнопки действий: - Открыть — переход на страницу /folder/{id} - Переименовать — открывает форму для нового имени - Удалить — подтверждение удаления

    События: - @open — открыть папку - @rename — переименовать - @delete — удалить

    4.5 FolderTree (дерево папок)

    Компонент для отображения иерархической структуры папок.

    Пропсы: - folders — массив папок - currentFolderId — ID текущей папки

    Отображает: - Вложенный список папок с отступами - Возможность раскрывать/сворачивать вложенные папки - Подсветка текущей папки

    Используется для: - Навигации по папкам - Выбора папки при перемещении файлов

    4.6 Breadcrumbs (хлебные крошки)

    Компонент навигации по пути к текущей папке.

    Пропсы: - path — массив объектов {id, name} от корня до текущей папки

    Отображает: - Последовательность ссылок: Корень → Папка1 → Папка2 → Текущая

    Функции: - Клик по любой части пути ведёт в соответствующую папку - Показывает текущее местоположение пользователя

    4.7 UploadForm (форма загрузки)

    Компонент для загрузки файлов.

    Пропсы: - currentFolderId — ID папки, в которую загружаются файлы

    Отображает: - Кнопку "Выбрать файлы" - Список выбранных файлов - Прогресс загрузки - Кнопку "Загрузить"

    Функции: - Выбор нескольких файлов через input - Отображение имён и размеров выбранных файлов - Загрузка через API /api/files/bulk_upload/ - Индикация прогресса - Очистка формы после загрузки

    4.8 CreateFolderForm (создание папки)

    Компонент для создания новой папки.

    Пропсы: - currentFolderId — ID текущей папки (родительской)

    Отображает: - Кнопку "Создать папку" - Модальное окно с полем ввода имени

    Функции: - Ввод имени новой папки - Валидация (имя не пустое) - Создание через API POST /api/folders/ - Обновление списка после создания

    4.9 ShareModal (модальное окно расшаривания)

    Компонент для создания публичной ссылки на файл.

    Пропсы: - fileId — ID файла - show — флаг отображения

    Отображает: - Заголовок с именем файла - Поле для ввода времени жизни ссылки (минуты) - Поле для ввода лимита скачиваний - Кнопку "Создать ссылку" - Сгенерированную ссылку (после создания) - Кнопку "Копировать"

    Функции: - Создание ссылки через API /api/files/{id}/share/ - Копирование ссылки в буфер обмена - Закрытие модального окна

    4.10 ConfirmDialog (диалог подтверждения)

    Универсальный компонент для подтверждения действий.

    Пропсы: - title — заголовок - message — сообщение - show — флаг отображения

    События: - @confirm — подтверждение действия - @cancel — отмена

    Используется для: - Подтверждение удаления файла - Подтверждение удаления папки - Подтверждение выхода из аккаунта

    4.11 LoginForm (форма входа)

    Компонент страницы входа.

    Отображает: - Поле ввода имени пользователя - Поле ввода пароля - Кнопку "Войти" - Ссылку на регистрацию

    Функции: - Валидация полей - Вызов API /api/auth/jwt/create/ - Сохранение токена в localStorage - Редирект на главную при успехе - Отображение ошибки при неверных данных

    4.12 RegisterForm (форма регистрации)

    Компонент страницы регистрации.

    Отображает: - Поле ввода имени пользователя - Поле ввода email (опционально) - Поле ввода пароля - Поле подтверждения пароля - Кнопку "Зарегистрироваться" - Ссылку на вход

    Функции: - Валидация полей (совпадение паролей) - Вызов API /api/auth/users/ - Автоматический вход после регистрации - Отображение ошибок валидации

    4.13 ProfileForm (форма профиля)

    Компонент страницы профиля.

    Отображает: - Текущее имя пользователя - Текущий email (с возможностью редактирования) - Форму смены пароля - Кнопку "Сохранить"

    Функции: - Загрузка данных через API /api/auth/users/me/ - Обновление email через PATCH /api/auth/users/me/ - Смена пароля через POST /api/auth/users/set_password/ - Валидация полей - Отображение успешных изменений
